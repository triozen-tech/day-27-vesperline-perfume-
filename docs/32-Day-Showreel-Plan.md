# 32-Day Showreel Plan (living copy)

The editable version of `32-Day-Showreel-Plan.pdf`. **This file wins where they differ.** Built days show what was actually built (codes in `docs/SITES-SUMMARY.md`). Planned brand names are working titles: each is checked before its day and renamed to a fictional name if it belongs to a real company or trademark (lesson 142).

Hero video letters: A push-in · B 360° orbit / product spin · C fly-through a space · D transformation (start → end frame) · E reveal from darkness · F splash / floating ingredients.

Changes from the PDF (2026-10-10):
- Day 8 was built as the cake shop (Crumb & Co), not luxury villas. Luxury villas move to the free Day 21 slot, since the bakery is done.
- Day 16 is Kanak Jewels only, with no real-brand alternative. Its look is chosen from the reference picks and is not locked to dark luxury.
